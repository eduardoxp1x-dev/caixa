# Caixa

Registro de entradas e saídas (pessoal + negócio). PWA instalável no celular; os dados ficam no IndexedDB do aparelho — faça backup em Ajustes.

- Rodar local: `npm start` → http://localhost:5173
- Testes: `npm test`
- Ao publicar mudanças, aumente `VERSAO` em `sw.js` para os celulares pegarem a versão nova.
